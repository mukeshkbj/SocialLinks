# Store listing copy

## Name
Social Links – right-click open, copy & add

## Short description (≤132 characters)
Paste your LinkedIn, GitHub and other profile links into any form with one right-click. No access to your browsing.

## Category
Productivity

## Full description
Filling in another job application or hackathon form? Right-click in the field, choose **Social links › LinkedIn › Paste here**, and it's filled in.

Social Links keeps your profile links in your browser's own right-click menu on every website.

**Right-click anywhere to:**
• Paste any saved link straight into the text box you clicked
• Open or copy any saved link
• Add the link, page or text you right-clicked — it recognises the platform and username automatically
• Add or edit any platform (+ means not added yet, ✎ means saved)
• Switch between profiles such as Work and Personal

**From the toolbar button:**
• Add links by username or URL, with validation that catches typos and wrong sites
• Add any other site under your own name — Kaggle, Behance, your portfolio
• Reorder by drag or keyboard, search, undo removals
• Share card: a QR code that phones scan straight into contacts, plus a vCard file
• Back up to a file and restore with a preview

**Private by design:** Social Links cannot read the websites you visit. It only types into a page when you choose Paste here, and only into that box. It has no access to your tabs, history or clipboard contents, makes no network requests and collects no data. Your links sync through your own browser account.

Works with LinkedIn, GitHub, X (Twitter), Instagram, YouTube, Facebook, TikTok, Medium, DEV, Stack Overflow, websites, email and any other link.

## 5 feature bullets
1. Right-click in any text box to paste your LinkedIn, GitHub and other profile links.
2. Add a link by right-clicking it — the platform and username are detected for you.
3. Separate Work and Personal profiles, switchable from the menu.
4. Share card with QR code and vCard, plus backup and restore.
5. Never reads the pages you visit, no tracking, no network requests.

## Single purpose (Chrome Web Store)
Save the user's social and profile links and let them paste, open, copy and add them from the browser's right-click menu.

## Permission justifications (Chrome Web Store)
- **contextMenus:** shows the Social links right-click menu.
- **storage:** saves the user's links and profiles.
- **offscreen:** a hidden extension page performs the "Copy" menu action, because service workers cannot use the clipboard.
- **clipboardWrite:** writes the chosen link to the clipboard when the user picks Copy. The clipboard is never read.
- **activeTab:** when the user picks "Paste here" in the right-click menu, grants temporary access to that tab only.
- **scripting:** inserts the chosen link into the text box the user right-clicked. The injected function reads nothing from the page.
- **favicon (optional):** shows website icons for the user's saved links, only after the user turns on "Show site icons".
- **Remote code:** none. All code, including the QR encoder, is bundled.

## Data usage disclosures
Collects no user data. Not sold or transferred; not used for unrelated purposes or creditworthiness.
